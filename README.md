# Королевство Морвейн

Игра-книга в браузере. Три главы, ветвление, чекпоинты, кубик.

🎮 **Играть:** https://makpoc-hub.github.io/GameBook1/

## О проекте

**Королевство Морвейн** — браузерная игра-книга. Вы — странник, идущий через Сумрачный бор, шахты Предтеч и путь к Чёрному замку. В каждой сцене — выбор, от которого зависит судьба героя.

**Три главы:**
1. **Сумрачный бор** — лес, знаки, встреча с Ордриком.
2. **Шахты Предтеч** — старцы, машины, ядро, Стражи.
3. **Путь к Ордрику** — брошенный лагерь, финальный бой, эпилоги.

**Особенности:**
- Ветвление сюжета, три параллельные ветки.
- Система чекпоинтов — можно вернуться к любому моменту.
- Кубик для проверок и боёв.
- Стартовые артефакты, ядро Предтеч, зеркало, свитки.
- Внезапная концовка — если найдёшь.

## Управление

### Мышь или касание
- **Клик по карте** — выбор действия.
- **Клик по предмету в мешке** — открыть описание.
- **Клик по премиум-ячейке** — купить дополнительный слот.

### Клавиатура
- `1`–`9` — выбор карты с клавиатуры.
- `H` — открыть «История» (меню чекпоинтов).
- `Z` — шаг назад (стоит 1 осколок).
- `Esc` — закрыть мешок или открытое окно.

## Документация

- **`Сюжет.txt`** — полное сюжетное описание: мир, персонажи, хронология, бой, концовки, предметы.
- **`Правила1.txt`** — принципы разработки. Часть 1: концепция (философия, текст, выбор игрока, структура, проверки).
- **`Правила2.txt`** — принципы разработки. Часть 2: реализация (механики, согласованность текста и интерфейса, чек-листы).

## Технологии

- **HTML, CSS, JavaScript.** Без фреймворков.
- Все изображения — SVG. Эмодзи в интерфейсе запрещены.
- Сохранение — через `localStorage`.

## Структура проекта

Проект — набор `.js`-файлов, подключаемых по порядку в `index.html`. Каждый файл отвечает за свой слой:

- **`engine_*.js`** — движок: состояние, бой, отрисовка, чекпоинты, диалоги.
- **`story_ch*_*.js`** — сюжетные тексты, разбитые по главам.
- **`itemcards_*.js`** — арты предметов (SVG).
- **`icons.js`, `bg.js`, `cardbacks.js`** — графика интерфейса.
- **`settings.js`** — настройки, профиль, валюты.
- **`tests.js`** — временный файл для просмотра графики (в игре не используется).
